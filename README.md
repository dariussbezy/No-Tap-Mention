# No Tap Mention

Disable tapping a message author's name to insert a mention.

Avatar taps and long presses keep working. Disable the plugin to get Discord's behavior back.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of No Tap Mention. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
